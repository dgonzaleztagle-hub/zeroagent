Preferencias locales de Studio

Revisa la separación de credenciales y administra los respaldos de esta herramienta local.

Separación de credenciales

Studio es local. Las credenciales de Supabase se protegen en el vault cifrado y las claves del modelo o Zavu viven en el entorno instalable del cliente.

Motor único de pruebas

El Playground usa el runtime empaquetado. Proveedor, modelo y clave se configuran como variables del proceso local; ninguna API key se guarda en este navegador.
